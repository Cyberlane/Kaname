# Native parity ledger

Parity means equivalent semantics, state language, authority boundaries, and accessibility—not pixel identity.

Allowed states: `proposed`, `catalogued`, `production-adopted`, `automated-qualified`, `manually-qualified`, and `not-applicable`.

| Spacing/radius/size/motion | catalogued | catalogued | production-adopted in pilot components | catalogued resources | proposed beyond component CSS |
| Status vocabulary | catalogued | catalogued | production-adopted in pilot | proposed component adapter | proposed component adapter |
| Shared semantic components | catalogued | proposed | production-adopted pilot | proposed | proposed |

| Assistive technology | manual proof pending | manual proof pending | manual proof pending | Narrator pending | Orca pending |
| Screenshot automation | macOS catalog + Dev receipt | deterministic simulator script | synthetic native script | pending target host | pending target host |

Update rows whenever evidence changes. Source presence alone never advances a row to automated- or manually-qualified.
